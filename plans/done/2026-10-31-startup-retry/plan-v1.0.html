Startup retry, SSH only, SECURE default

Status: done 2026-10-31 · shipped in app 0.2.5, image 0.2.6, CLI 0.2.0 · approved choices 1A 2A 3A 4A 5A (user, 2026-10-31)

TL;DR

  • SSH only: remove the Cloudflare connection. Old LOBO_CONNECTION, CF_TUNNEL_TOKEN and LOBO_DOMAIN keys are ignored and never sent to a pod.
  • SECURE default: rent SECURE first; COMMUNITY only as a fallback.
  • Retry: any startup failure rents a new pod, up to 10 attempts, each with its reason; then stop with the last reason.
  • Clear reason: an agent that fails before its API starts still serves its error for 60 s before it deletes the pod. A pod that disappears without a reason says so.
  • Release: image 0.2.6, app 0.2.5, CLI 0.2.0 (Homebrew) from one tested commit. Not in scope: removing cloudflared from the agent and image.

Why

The user's old config had CF_TUNNEL_TOKEN and LOBO_DOMAIN; Settings saved LOBO_CONNECTION=cloudflare. The pod tunnel never connected (Cloudflare 1033), the app saw only "pod is gone (deleted) during startup in phase image", and stopped. SSH mode on the same image: Ready in 46.8 s.

Risks

  • 10 attempts on a deterministic agent error cost about 10 × 30 s of pod time (~$0.10 at $1.19/h). Accepted.
  • SSH mode needs hosts with public TCP ports; SECURE has them. COMMUNITY fallback may have fewer.
  • Users who relied on the public HTTPS domain lose it. No known users.
